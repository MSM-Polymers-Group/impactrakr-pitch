Quick start

The fastest way to see real data moving through ImpacTrakr.

1. The Excel/CSV path (recommended for a first pilot)

Send a structured export of your existing records — whatever format you already keep them in. There's no fixed template requirement on day one: the first pilot's data is used to define the import layout, which then becomes the standard template for onboarding the next organization.

2. Organization setup

Each participant in your chain of custody (generator, hauler, processor, recycler — see Roles) needs an active homologation record before data attributed to them is trusted by the validation engine.

3. First validation run

Once imported, records run against whichever rule pillar(s) your project has pinned (see Standard). Expect the first run to surface gaps — that's the point of a pilot: finding out what's missing or inconsistent in your data before scaling it up.

4. Programmatic access

Machine clients authenticate with an organization-scoped API key rather than a user login (see Security model).

Confirm before publishing: a real quick-start with live endpoint examples needs the public API reference (see API) to exist first — deliberately not fabricating curl examples against endpoints that aren't confirmed live and stable yet.
