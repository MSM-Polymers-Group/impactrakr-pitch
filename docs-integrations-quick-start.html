Início rápidoQuick startInicio rápido

O jeito mais rápido de ver dados de verdade se movendo pela ImpacTrakr.The fastest way to see real data moving through ImpacTrakr.La forma más rápida de ver datos reales moviéndose a través de ImpacTrakr.

1. O caminho Excel/CSV (recomendado para o primeiro piloto)The Excel/CSV path (recommended for a first pilot)El camino Excel/CSV (recomendado para un primer piloto)

Envie uma exportação estruturada dos seus registros existentes — qualquer formato que você já use. Não existe um template fixo obrigatório no dia um: os dados do primeiro piloto são usados para definir o layout de importação, que depois vira o template padrão para o onboarding da próxima organização.Send a structured export of your existing records — whatever format you already keep them in. There's no fixed template requirement on day one: the first pilot's data is used to define the import layout, which then becomes the standard template for onboarding the next organization.Envíe una exportación estructurada de sus registros existentes — el formato que ya use. No hay un template fijo obligatorio desde el primer día: los datos del primer piloto se usan para definir el layout de importación, que luego se convierte en el template estándar para incorporar a la siguiente organización.

2. Configuração de organizaçãoOrganization setupConfiguración de organización

Cada participante na sua cadeia de custódia (gerador, transportador, processador, reciclador — veja Papéis) precisa de um registro de homologação ativo antes que dados atribuídos a ele sejam confiados pelo motor de validação.Each participant in your chain of custody (generator, hauler, processor, recycler — see Roles) needs an active homologation record before data attributed to them is trusted by the validation engine.Cada participante en su cadena de custodia (generador, transportista, procesador, reciclador — vea Roles) necesita un registro de homologación activo antes de que los datos atribuidos a él sean confiados por el motor de validación.

3. Primeira rodada de validaçãoFirst validation runPrimera ejecución de validación

Depois de importados, os registros rodam contra o(s) pilar(es) de regras que o seu projeto fixou (veja Padrão). Espere que a primeira rodada exponha lacunas — é justamente o ponto de um piloto: descobrir o que falta ou está inconsistente nos seus dados antes de escalar.Once imported, records run against whichever rule pillar(s) your project has pinned (see Standard). Expect the first run to surface gaps — that's the point of a pilot: finding out what's missing or inconsistent in your data before scaling it up.Una vez importados, los registros se ejecutan contra el o los pilares de reglas que su proyecto fijó (vea Estándar). Espere que la primera ejecución exponga brechas — ese es justamente el punto de un piloto: descubrir qué falta o es inconsistente en sus datos antes de escalarlo.

4. Acesso programáticoProgrammatic accessAcceso programático

Clientes máquina se autenticam com uma chave de API por organização em vez de um login de usuário (veja Modelo de segurança).Machine clients authenticate with an organization-scoped API key rather than a user login (see Security model).Los clientes máquina se autentican con una clave de API por organización en lugar de un login de usuario (vea Modelo de seguridad).
