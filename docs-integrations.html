API

O que está disponível hoje para clientes máquina, e o que está no roadmap.What's available today for machine clients, and what's roadmap.Qué está disponible hoy para clientes máquina, y qué está en el roadmap.

Hoje: importação estruturada de Excel/CSV é o caminho padrão e mais rápido pra um piloto — permite que um cliente valide a plataforma contra seus dados históricos reais antes de qualquer um dos lados investir tempo de engenharia. Chaves de API por organização já estão disponíveis hoje pra clientes máquina/ERP. Integração direta com ERP como caminho padrão de onboarding pra clientes maiores está no roadmap, construída sobre a mesma autenticação por chave de API já em vigor.Today: structured Excel/CSV import is the default, fastest path to a pilot — it lets a client validate the platform against their real historical data before either side invests engineering time. Organization-scoped API keys are available today for machine/ERP clients. Direct ERP integration as the default onboarding path for larger clients is roadmapped, building on the same API-key authentication already in place.Hoy: la importación estructurada de Excel/CSV es el camino por defecto y más rápido hacia un piloto — permite que un cliente valide la plataforma contra sus datos históricos reales antes de que cualquiera de las partes invierta tiempo de ingeniería. Las claves de API por organización ya están disponibles hoy para clientes máquina/ERP. La integración directa con ERP como camino de onboarding por defecto para clientes más grandes está en el roadmap, construida sobre la misma autenticación por clave de API ya vigente.
