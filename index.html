As perguntas que recicladores e auditores fazem.The questions recyclers and auditors ask.

Isso é realmente compliance?Is this really compliance?

O backbone do stack é a Regulação (UE) 2024/1157 mais RecyClass. As regras que rodam sobre cada evento são as mesmas que um VVB acreditado usa para julgar o pacote. Sem paralelo, sem interpretação própria.The stack backbone is EU Regulation 2024/1157 plus RecyClass. The rules that run over every event are the same ones an accredited VVB uses to judge the pack. No parallel track, no proprietary interpretation.

Precisamos aceitar a palavra da ImpacTrakr como definitiva?Do we have to take ImpacTrakr's word for it?

Não. A palavra final é do seu auditor terceirizado. A ImpacTrakr entrega o registro pré-validado e o hash chain para que o auditor reproduza cada decisão sobre o mesmo payload e chegue no mesmo resultado, bit-a-bit.No. The final word is your third-party auditor's. ImpacTrakr delivers the pre-validated record and the hash chain, so the auditor can reproduce every decision on the same payload and reaches the same outcome, bit-for-bit.

E se os dados forem editados depois?What if the data is edited later?

Não há edição. Correção é um evento novo, selado no mesmo hash chain. A trilha só cresce, nunca é reescrita, e a diferença aparece na auditoria.There is no editing. A correction is a new event, sealed on the same hash chain. The trail only grows, never gets rewritten, and the delta shows up in the audit.

Não. Cada DPP tem URL pública verificável pelo comprador sem login. O que exige acesso é o audit pack completo, entregue ao verificador terceirizado.No. Each DPP has a public URL the buyer can verify without login. What requires access is the full audit pack, delivered to the third-party verifier.

Para auditores e certificadoresFor auditors and certifiers
Isso altera meu papel como certificador?Does this change my role as certifier?

Não altera o papel, muda o método. Em vez de reconstruir dossiê no fim do ano, você recebe um registro pré-validado, contínuo, e valida a amostragem que quiser sobre a trilha imutável.The role doesn't change, the method does. Instead of reconstructing a dossier at year-end, you get a continuous pre-validated record and sample whatever you want against the immutable trail.

Para reguladoresFor regulators
Regulador · como isso conversa com DIWASS e DPP?Regulator · how does this speak with DIWASS and DPP?

O backbone regulatório é o Módulo 1 (Reg. 2024/1157 + DIWASS). PPWR, ESPR e DPP entram como módulos adicionais, seguindo o mesmo padrão de regras. Cada framework novo é um módulo, não uma reescrita.The regulatory backbone is Module 1 (Reg. 2024/1157 + DIWASS). PPWR, ESPR and DPP plug in as additional modules following the same rule pattern. Each new framework is a module, not a rewrite.
